**D. PYQ and Testing Curriculum**

These should **not replace concept teaching videos**.

**PYQ-1 — Topic-wise Previous Year Questions**

After completing each topic:

**Concept Video → Faculty Lecture → Basic Practice → CAT-level Questions → CAT PYQs → Topic Test**

**PYQ-2 — DILR Set Practice**

Students should solve complete CAT sets rather than isolated questions.

**PYQ-3 — VARC PYQ Analysis**

Each wrong answer should record:

**Passage misunderstanding / inference error / option-elimination error / scope error / rushed selection.**

**TEST-1 — Topic Test**

10–20 questions immediately after topic completion.

**TEST-2 — Module Test**

After completing a complete module such as Arithmetic or Algebra.

**TEST-3 — Sectional Test**

40-minute CAT-equivalent test.

**TEST-4 — Full CAT Mock**

VARC + DILR + QA.

**Recommended structure inside your AI CAT platform**

For **every one of the above subtopics**, I recommend storing the content in this format:

**Module → Subtopic → Faculty Recorded Lecture → One Curated YouTube Video → Faculty Notes/PDF → Solved Examples → Level-1 Questions → Level-2 Questions → CAT PYQs → Topic Quiz → AI Gap Analysis → RAG Doubt Clearing → Personalised Remedial Questions → Mastery Test.**

For example:

**QA-1.1 Percentages**  
→ TIU faculty lecture  
→ Rodha single reference video  
→ Notes  
→ 10 worked examples  
→ 25 foundation questions  
→ 25 CAT-level questions  
→ 15 PYQs  
→ 15-question diagnostic test  
→ AI identifies weak concepts such as _successive percentage change_  
→ RAG explanation  
→ 10 dynamically generated remedial questions  
→ reassessment.

This is the format I would use for the **final university CAT curriculum**.
